# FluentMC keybinds

Shipped with the pack so everyone starts with the same layout. Vanilla keys are untouched. Change anything under Options → Controls.

## In the world

| Key | Action | Mod |
|---|---|---|
| **B** | Open backpack | Traveler's Backpack |
| **V** | Cycle backpack tool / hose mode | Traveler's Backpack |
| **N** | New waypoint | Xaero's Minimap |
| **U** | Waypoint list | Xaero's Minimap |
| **M** | World map | Xaero's World Map |
| **Y** | Minimap settings | Xaero's Minimap |
| **Z** | Enlarge minimap (hold) | Xaero's Minimap |
| **H** | Open storage terminal remotely | Tom's Simple Storage |
| **C** | Zoom (hold, scroll to adjust) | Zoomify |
| **K** | Toggle shaders | Iris |
| **I** | Shader pack menu | Iris |
| **F7** | Light-level overlay | Lighty |
| **F8** | Toggle light overlay mode | Lighty |
| **Mouse 5** | Ping a location for your friends | Ping Wheel |
| **Shift + right-click** | Pick up a block or mob | Carry On |
| **Shift** while looking at a block | More details in the Jade tooltip | Jade |
| **Shift + mine a log** | Fell the whole tree | FallingTree |
| **Shift + mine ore** | Vein-mine | VeinMiner |
| **Shift + right-click stairs or slab** | Sit | Sit |
| **F3** | Debug screen | vanilla |

## In menus

| Key | Action | Mod |
|---|---|---|
| **R** over empty space | Sort inventory or container | Inventory Profiles Next |
| **R** over an item | Show recipes | JEI |
| **U** over an item | Show uses | JEI |
| **A** over an item | Bookmark | JEI |
| **F** | Focus JEI search | JEI |
| **O** | Toggle JEI overlay | JEI |
| **Delete** | Trash the held item (TrashSlot) | TrashSlot |
| **T** | Toggle the trash slot | TrashSlot |
| **Shift + Delete** | Empty the trash slot | TrashSlot |
| **Tab** / **Ctrl+K** / **Shift+K** | Refill last recipe / compress stacks (crafting grid buttons do the same) | Crafting Tweaks |
| **Right-click** a shulker box in inventory | Open it in place | Easy Shulker Boxes |

Chat: type `/home`, `/sethome <name>`, `/tpa <player>`, `/back`, `/spawn` (Essential Commands). Waystones are activated by walking up to them and right-clicking.
